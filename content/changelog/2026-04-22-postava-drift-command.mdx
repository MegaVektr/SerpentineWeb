title: "postava drift detects state deviation"
---

The new `postava drift` command compares a host's current configuration against the last applied baseline. It flags manual changes to firewall rules, SSH settings, kernel parameters, and fail2ban configuration, and reports them per environment. Drift events can be routed to the same webhook channel as health-check failures.
